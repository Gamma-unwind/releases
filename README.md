# GAMMA-UNWIND releases

Client packages of GAMMA-UNWIND, an options open-interest scanner with a local dashboard and Telegram alerts.

- `latest.json` and `SHA256SUMS` on this site are read by the in-place updater (`Update GAMMA.cmd` / `update.sh`).
- The client ZIPs are attached to the GitHub Releases of this repository.

Alerts are information only. They are not investment advice and not a recommendation to trade.
